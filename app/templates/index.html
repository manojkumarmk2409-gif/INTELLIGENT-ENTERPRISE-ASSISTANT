    REST API Documentation

    This enterprise backend provides standard RESTful endpoints for integration into enterprise workflows.

    POST /process_pdf

    Uploads a PDF file, extracts text, and indexes chunks into the vector store.

    curl -X POST -F "pdf_file=@report.pdf" http://localhost:5000/process_pdf
    POST /summarize_pdf

    Extracts text and generates a structured summary with key takeaways.

    curl -X POST -F "pdf_file=@report.pdf" http://localhost:5000/summarize_pdf
    POST /ask_question

    Performs semantic similarity retrieval and returns relevant snippets.

    curl -X POST http://localhost:5000/ask_question \
  -H "Content-Type: application/json" \
  -d '{"question": "What is the primary methodology?"}'
